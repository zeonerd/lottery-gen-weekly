# weekly-num

연금복권720+ 주간 번호 추천 시스템 (개인용).

매주 수요일 20:00, 과거 회차를 분석해 5조의 추천 번호를 텔레그램으로 전달합니다.

## ⚠️ 먼저 읽어야 할 것

**이 시스템은 당첨 확률을 높이지 않습니다.**

연금복권720+의 추첨은 매 회차 완전히 독립적입니다. 과거 당첨 번호는 이번 회차에 아무런 정보도 주지 않으며, 어떤 분석·소거 규칙도 1등 확률 `1/5,000,000`을 바꾸지 못합니다.

이 프로젝트는 **번호를 고르는 과정에 근거와 재미를 더하는 도구**입니다. 상세한 논증은 [기획서 §0](docs/PRD.md)에 있습니다.

수학적 근거를 가진 유일한 설계 변수는 **분산 배치**입니다. 5장의 뒷자리를 서로 다르게 두면 기대값은 그대로면서 "매주 뭐라도 걸릴 확률"이 9% → 45%로 바뀝니다([§F6](docs/PRD.md)).

## 데이터 출처

동행복권 공식 엔드포인트를 사용합니다.

```
GET https://www.dhlottery.co.kr/pt720/selectPstPt720WnList.do
```

전 회차를 한 번에 반환하므로 주기적 크롤링이 필요 없습니다. `robots.txt`상 `/pt720/*`는 허용 범위이며, 주 1~2회만 요청합니다.

## 설정

```bash
cp .env.example .env
```

`.env`에 텔레그램 봇 토큰과 `chat_id`를 채웁니다. **이 파일은 절대 커밋하지 마십시오** (`.gitignore`에 등록되어 있습니다).

# weekly-num

연금복권720+ 주간 번호 추천 시스템 (개인용).

매주 수요일 20:00, 과거 회차를 분석해 5조의 추천 번호를 텔레그램으로 전달합니다.

## ⚠️ 먼저 읽어야 할 것

**이 시스템은 당첨 확률을 높이지 않습니다.**

연금복권720+의 추첨은 매 회차 완전히 독립적입니다. 과거 당첨 번호는 이번 회차에 아무런 정보도 주지 않으며, 어떤 분석·소거 규칙도 1등 확률 `1/5,000,000`을 바꾸지 못합니다.

이 프로젝트는 **번호를 고르는 과정에 근거와 재미를 더하는 도구**입니다. 상세한 논증은 [기획서 §0](docs/PRD.md)에 있습니다.

수학적 근거를 가진 유일한 설계 변수는 **분산 배치**입니다. 5장의 뒷자리를 서로 다르게 두면 기대값은 그대로면서 "매주 뭐라도 걸릴 확률"이 9% → 45%로 바뀝니다([§F6](docs/PRD.md)).

## 백테스트 결과 — 무엇이 효과가 있고 무엇이 없는가

최근 226회차를 대상으로 회차당 400회씩 시뮬레이션한 결과입니다(`weekly-num backtest`).

| 전략 | 적중률 (95% CI) | 이론값 | 3~7등 주당수익 | 회수율 |
|---|---|---|---|---|
| 무작위 (기준선) | 40.52% [34.1, 46.9] | 40.95% | 969원 | −80.6% |
| 무작위 + R8 | 49.96% [43.4, 56.5] | 50.00% | 987원 | −80.3% |
| **전체 규칙 + R8** | 53.88% [47.4, 60.4] | 50.00% | 1,094원 | −78.1% |
| 집중 (5장 동일) | 10.81% [6.8, 14.9] | 10.00% | 1,166원 | −76.7% |

**효과를 분해하면 이렇습니다.**

| 무엇이 | 적중률 변화 | p-value | 판정 |
|---|---|---|---|
| R8 분산 배치 | 40.52% → 49.96% (**+9.44%p**) | 0.0437 | 유의 |
| 소거 규칙 R1~R6 | 49.96% → 53.88% (+3.92%p) | 0.4040 | **유의하지 않음** |

### 읽는 법

**R8만이 실제 효과입니다.** 그것도 통계적 발견이 아니라 산술입니다 — 뒷자리 5개를 겹치지 않게 두면 10개 중 정확히 5개를 덮고, 겹치도록 두면 `1-(9/10)^5 = 40.95%`로 떨어집니다. 관측값이 이론값과 맞는지 확인하는 것 이상의 의미는 없습니다.

**소거 규칙 R1~R6의 기여는 유의하지 않습니다. 이것이 정상이며 버그가 아닙니다.** 추첨이 매 회차 독립이므로 과거 데이터로 무엇을 지우든 확률은 변하지 않습니다.

**"전체 규칙"의 점추정치(53.88%)가 이론값 50%보다 높게 나온 것은 잡음입니다.** 신뢰구간 [47.4, 60.4]가 50%를 포함합니다. 소거는 뽑을 후보를 좁힐 뿐, 뒷자리 5개를 덮는다는 사실은 바꾸지 못하므로 커버리지는 어떤 경우에도 정확히 50%입니다.

**회수율은 모든 전략에서 −77~−81%입니다.** 어떤 배치로도 기대값은 같으며, 바뀌는 것은 "자주 조금"이냐 "드물게 크게"냐 하는 분산뿐입니다. 3~7등 기준 주당 수익 표준편차는 분산 배치 9,007원, 집중 배치 11,361원입니다.

> 신뢰구간은 시행 수(90,400)가 아니라 **주 수(226)** 기준입니다. 같은 회차를 여러 번 시행한 결과는 서로 독립이 아닙니다. 실제 추첨은 주당 한 번뿐이라, 시행 수를 표본 수로 쓰면 구간이 실제보다 좁아져 잡음이 발견처럼 보입니다.

## 데이터 출처

동행복권 공식 엔드포인트를 사용합니다.

```
GET https://www.dhlottery.co.kr/pt720/selectPstPt720WnList.do
```

전 회차를 한 번에 반환하므로 주기적 크롤링이 필요 없습니다. `robots.txt`상 `/pt720/*`는 허용 범위이며, 주 1~2회만 요청합니다.

## 설정

```bash
cp .env.example .env
```

`.env`에 텔레그램 봇 토큰과 `chat_id`를 채웁니다. **이 파일은 절대 커밋하지 마십시오** (`.gitignore`에 등록되어 있습니다).
